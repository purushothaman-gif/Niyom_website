# Client Portal promo — shot list and narration

Generated by `npm run docs` in `tools/promo-video`. Timecodes are measured off
the rendered clips, not estimated.

**Voice** `Rishi` at 168 wpm (macOS `say`). To re-record with a human
voice, use the narration column below — each line is timed to its own scene, so
a replacement take should be cut to the same in/out points.

**Footage** is the real Client Portal, driven live in Chromium against the
sample account (`NIYOM5678C`). Every name, security, statement and figure on
screen is invented; the portal's own "Sample portal" banner is visible
throughout, and scenes showing money additionally carry:

> Illustrative figures from a sample portal. Not a representation of actual or expected earnings.

**Aspect ratios** — 1920×1080 and
1080×1920. The vertical cut is filmed
at the portal's own phone layout, not a scaled-down desktop.

## Re-cutting

| Want to | Do |
|---|---|
| Change a line | Edit `src/films/client.ts`, then `npm run all -- client` |
| Re-shoot one scene | `PROMO_ONLY=bonds npm run capture -- client landscape`, then `npm run build -- client` |
| Use a better voice | Download an Enhanced voice in System Settings → Accessibility → Spoken Content → Manage Voices, then `PROMO_VOICE="Ava (Premium)" npm run all -- client` |
| Add the ident to the vertical cut | `PROMO_IDENT=landscape,vertical npm run build -- client` |
| Add music | Drop an mp3 in `audio/` — currently unmixed; no licensed track ships with the repo |
